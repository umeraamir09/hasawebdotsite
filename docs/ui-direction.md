## Initial setup

Warm neutral surfaces, the lime accent, DM Sans and the existing control language. Focused forms, prominent headings, generous whitespace, visible progress and stable navigation (inspired by Linktree screenshots, which define no copy, limits, colors or guarantees). The Profile step shows avatar and banner previews and uses the shared crop dialogs (reposition, zoom, Reset, Apply crop, Cancel). Optional Skip actions appear only after required setup. Review uses the real shared renderer with desktop/mobile switching. See [onboarding.md](onboarding.md).
