# Imported avatar decorations

The owner replaced the original Leaf, Orbit and Frame static SVG proposals with
the ginger cat and animated hands from their existing portfolio. Those three SVG
files have been removed. The actual imported component, CSS, assets and generator
are in `apps/web`; catalog entries identify their implementations and hashes.

See the import documentation for the
unchanged source component, independent wrapper, review and regeneration commands.
The gallery must render the actual component for both variants. Hands is inline
SVG/CSS choreography, not a missing image file. Catalog default decoration remains
absent. The import does not provision the source portrait photos into owner drafts.
