# Phase 11E acceptance criteria

1. A versioned approved catalog records exactly six unique theme IDs (`leaf`, `violet`, `clay`, `matcha`, `strawberry`, `coffee`), each with light/dark semantic colors, curated font IDs/assets/licenses/fallbacks, exactly two decoration IDs (`cat`, `hands`), assets/geometry, one template ID and explicit defaults. The additions match the Figma palette export.
2. Local font and decoration files exist, are nonempty, and have recorded SHA-256 digests and provenance. Fonts load locally in the palette review; cleaned cat assets and hands SVG/CSS load locally in the linked React review. Neither review makes third-party asset requests. Decorations preserve a clear avatar center and share placement over both Face Reveal images.
3. Automated checks cover all declared text/background and control/background pairs against WCAG 2.2 AA, 4.5:1 for normal text and 3:1 for control indicators. These checks do not claim to implement the future OKLCH custom-color generator or validate future rendered components.
4. The palette/font review shows consistent example content and layout across all six themes, both modes and every actual font. Linked local React specimens show both faithful decorations using the original source portraits and layout wrapper. All existing animation, interaction and reduced-motion checks remain required. Both reviews are fixtures with no owner-storage integration.
5. The package typechecks, relevant tests and repository checks pass. Results document read-only Figma evidence, the catalog's exact choices and remaining phase boundaries. Product/architecture/acceptance/roadmap scope consistently describes six themes and two animated decorations. The production pause/play policy has an explicit implementation phase; it is not claimed as implemented in the source review. The source generator's exact-byte failure and retained original clean assets are documented under the import's permitted environment exception.
6. The owner explicitly approves the catalog and defaults and decides whether to mark Phase 11E complete. The manifest and results record the approval; the roadmap can then be checked off. Actual provisioning remains Phase 12. This criterion was satisfied on October 17, 2026.
