# Avatar decoration import acceptance criteria

1. All three source files, seven named image/mask assets and the generator exist in the web package. Hash checks prove verbatim copying, except for the single permitted asset-map import change. The map contains only the two required entries, and runtime code has no dependency on the source checkout.
2. Root `npm run generate:avatar` invokes the verbatim generator with the pinned local dependency and normally must pass its output guard. The documented exception is limited to `Encoding changed the cleaned frames or animation timing.` on Node `22.22.1`, sharp `0.35.5`, libvips `8.18.7` and libwebp `1.6.0`, caused solely by the recorded hidden RGB differences beneath fully transparent pixels. Under that exception, retain both original source-verified clean assets, verify restoration after command failure, and record the nonzero result without claiming regeneration passed. The cleaned loop must still be 212 × 220 per frame with 32 frames, identical delays and infinite loop flag; alpha and visible pixels must remain unchanged. This exception waives no other source-fidelity, asset-integrity or generation failure and does not permit changing the generator guard.
3. The default cat and explicit hands variants render in an independent reusable wrapper and review page. Both remain correctly positioned at 360, 768 and 1280 px, with source 104/124 px responsive portrait sizes and no layout shift after loading.
4. Both portrait directions use the original diagonal wipe and stable image bounds. Clicking, Enter and Space toggle `aria-pressed`; in-progress toggles are guarded by `aria-disabled`. The two alt texts remain distinct and the inactive image is hidden from accessibility.
5. Cat animation changes frames through two complete cycles without interaction or live CSS filtering. Hands retain all poses, hearts, sparkles and six-second choreography. Reduced motion selects the cleaned still, stops hands and shimmer, and skips the wipe, including preference changes during a wipe.
6. Skeletons cover loading/error states, cached images become visible, and loading does not change wrapper dimensions. Global skeleton names and variable mappings work without source-site layout or fonts.
7. The approved gallery contains exactly cat and hands; the prior three static assets are removed. Review and checks understand image and SVG/CSS implementations rather than treating all decorations as static SVG files. Build/lint/typechecks and relevant tests pass or concrete source/environment limitations are recorded.
8. Documentation explains usage, review server, exact regeneration command, source fidelity and future production integration boundaries. Phase 11E can be checked off only after explicit catalog/completion approval. The owner gave that approval on October 17, 2026.
