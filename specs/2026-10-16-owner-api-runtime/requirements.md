# Phase 11A requirements

Measure the S-2 replacement before draft APIs depend on it. Keep the existing three Workers and Free plan. Route hot owner requests around OpenNext into a thin Hono jobs entry over an internal binding. Reuse Better Auth configuration, never a request's identity. Preserve exact authority/Origin checks, host-only signed cookies, persisted session expiry/revocation/deletion checks, owner isolation and revision checks.

Exercise the actual version 1 draft validator with representative components and a draft of exactly 1,048,576 UTF-8 bytes. Include an atomic content/private-progress write in isolated experiment storage. The storage/progress fixture is a measurement contract, not Phase 11B's permanent onboarding schema or Phase 13's public save API. Never provision a product portfolio or choose production appearance defaults here.

Collect local correctness evidence and deployed provider CPU/startup evidence, separating client elapsed time from CPU and cold candidates from warm samples. Target startup below 1,000 ms and warm request CPU p95 strictly below 10 ms. Record sampling, failures, cleanup and remaining limits. If it fails, record the measured result and a compatible revision for owner agreement before dependent implementation. Do not reduce the content ceiling or enable a paid plan.
